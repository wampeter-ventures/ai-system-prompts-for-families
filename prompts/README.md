# Prompts

Instructions you paste into ChatGPT, Gemini or Claude so the AI helps a child think instead of thinking for them. The kid and teen prompts are written in the child's own voice: it's their learning, and they should help write the rules.

| Prompt | For | Versions |
|---|---|---|
| [Thinking partner for kids](kids-6-to-11.md) | Ages 6–11 | Full, start-of-chat, short |
| [Study coach for teens](teens-12-to-17.md) | Ages 12–17 | Full, short |
| [Classroom assistant](classroom-assistant.md) | Teachers, one assignment at a time | Template |
| [Add-ons](add-ons.md) | Homework, math, writing, reading, creative projects, research, practice and more | Short lines to add to any prompt |

**Next:** [where to paste them](../how-to/set-up.md), then [test them](../how-to/test-it.md).

These prompts are written to work with any chatbot. Copy them, change them and share them ([CC BY 4.0](../LICENSE.md)).
