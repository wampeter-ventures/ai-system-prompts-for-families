# Contributing

We want this repo to get better with use. Parents and teachers who try these prompts know things we don't.

## What helps most

- **Test results.** You ran [the tests](how-to/test-it.md). Which app, which prompt, which tests passed and failed, and the date.
- **A better prompt.** A change that passes more tests, or a new [add-on](prompts/add-ons.md) for a situation we missed. Include the tests you ran.
- **A changed system prompt.** A company updated its instructions and our copy is out of date.
- **A clearer explanation.** Something in a guide that confused you.

## How

- **Not on GitHub, or not sure how?** Open an [issue](https://github.com/wampeter-ventures/ai-system-prompts-for-families/issues) and describe it in plain words. That's enough.
- **Comfortable with pull requests?** Edit the file and open one. Keep the writing plain and short, and keep the kept text in `what-the-ai-is-told/` word for word.

## Ground rules

- Write for a busy parent: short sentences, no jargon.
- Don't post a child's name, chats or other personal details. Describe what happened instead.
- Changes to prompts should come with test results, not only a good feeling. One good chat is not a test; the AI answers differently each time.
